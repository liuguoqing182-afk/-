P007: 1. 文档结论
P008: 系统读取正式群中的 AIMirror首屏配置发布成功! 通知，根据通知里实际出现的配置模块和配置对象，动态生成实体 Android 手机截图任务。
P009: 第二阶段只负责：
P010: 1. 接收并解析发布通知。
P011: 2. 拆分、合并本次发布涉及的截图对象。
P012: 3. 自动唤醒手机并打开 AIMirror。
P013: 4. 按模块进入对应页面。
P014: 5. 等待页面图片加载并按固定节点截图。
P015: 6. 给每张截图标注发布配置模块、配置对象和截图序号。
P016: 7. 把本次发布的所有模块拼成一张总图。
P017: 8. 当前仅把总图发送到测试群。
P018: 第二阶段不负责：
P019: 判断发布配置正确或错误。
P020: 判断新增、删除、排序、封面或字段修改是否符合预期。
P021: 根据截图内容输出业务上的成功、失败、通过或不通过。
P022: 执行国际化配置和新手引导页配置的手机截图。
P023: 在完整链路验收之前向正式群发送任何测试消息、状态消息或截图报告。
P024: 截图未完成 只表示自动化执行没有取得规定截图，不代表发布配置错误。

P066: 3. 系统边界和群聊规则
P067: 3.1 正式群
P068: 正式群是发布通知的只读来源。
P069: 只识别正文以 AIMirror首屏配置发布成功! 或 AIMirror首屏配置发布成功！ 开头的消息。
P070: 当前由历史消息轮询器每小时读取一次；轮询器启动后立即执行一次读取。
P071: 使用飞书 message_id 持久化去重，同一条发布通知只能生成一次自动化任务。
P072: 在完整链路跑通并得到明确批准之前，系统不得向正式群发送任何一句话。
P073: 3.2 测试群
P074: 自动化截图总图只允许发送到 FEISHU_TEST_CHAT_ID 对应的测试群。
P075: 启动前必须确认测试群 ID 与正式群 ID 不相同。
P076: 开发、联调、异常报告、测试截图和状态通知都只能进入测试群。
P077: 4. 端到端处理流程
P078: 1. 轮询器读取正式群最近消息。
P079: 2. 找到以 AIMirror首屏配置发布成功! 开头的发布通知。
P080: 3. 按飞书 message_id 去重。
P081: 4. 解析操作人、发布环境、配置模块和具体变更行。
P082: 5. 只接受当前规定的 DEV → PRO 正式发布通知。
P083: 6. 把六类发布配置映射为四类APP截图模块和两类人工审核模块。
P084: 7. 按“模块＋配置对象”合并重复变更，生成截图任务清单。
P085: 8. 为本次没有出现的APP截图模块生成“本次无修改”展示项。
P086: 9. 检查USB Android设备状态，唤醒手机并启动 AIMirror。
P087: 10. 按任务清单依次执行模型搜索、首页标签、Video标签和Filter标签截图。
P088: 11. 单个任务遇到页面找不到或图片加载超时，重启APP并从该任务流程开头重跑。
P089: 12. 给每张图片添加统一标题。
P090: 13. 把四类APP截图模块拼成一张总图。
P091: 14. 将总图发送到测试群并保存本地执行记录。
P092: 整体数据流：
P093: 正式群发布通知 → message_id 去重 → 发布内容解析 → 配置模块路由 → 配置对象合并 → 手机截图任务 → 异常重试 → 截图标题 → 单张总图 → 测试群

P169: 6.1 动态任务原则
P170: 模型名称来自发布消息，不写死。
P171: 标签名称来自发布消息，不写死。
P172: 模型ID作为发布变更的附加信息保存，不为每个ID单独生成截图。
P173: 同名标签出现在不同模块时必须分别生成任务。
P174: 同一对象在一条消息中重复出现时只生成一个任务。
P175: 截图对象顺序默认保持其在发布消息中第一次出现的顺序。
P176: 6.2 合并规则
P177: 模版修改
P178: 同一个模型同时出现以下多种变化时，合并为一个模型截图任务：
P179: 新增模型；
P180: 删除模型；
P181: 模型图片改变；
P182: 模型封面图系列改变；
P183: 模型字段改动。
P184: 示例：
P185: 模型Farewell Paw图片改变 模型Farewell Paw的封面图系列有改动 模型Farewell Paw有字段改动
P186: 只生成：
P187: 模版修改｜Farewell Paw｜1/1截图
P188: 标签类配置
P189: 同一模块、同一标签同时出现以下变化时，合并为一个标签截图任务：
P190: 标签模型排序改变；
P191: 新增模型；
P192: 删除模型；
P193: 标签组封面修改。
P194: 示例：
P195: 标签Baby的模型排序改变 新增了模型(所属标签Baby)[980] 标签Baby的组封面修改
P196: 只生成一个 Baby 标签任务，共4张截图。
P197: 7. 统一截图标题规则
P198: 每一张正常截图必须使用以下标题：
P199: 发布配置模块｜配置对象｜当前截图序号/该对象截图总数截图
P200: 强制示例：
P201: 模版修改｜Tiny Cleaner｜1/1截图 新首页配置｜Best Companion｜1/4截图 新首页配置｜New｜3/4截图 More Style Video配置｜Seedance 2.0｜2/4截图 More Style AI Filter配置｜Baby｜4/4截图
P202: 约束：
P203: 模块名称必须使用发布消息中的标准名称。
P204: 配置对象只能填写模型名或标签名。
P205: 序号按单个配置对象独立计算。
P206: 标题必须直接显示在图片上方或下方，不能只写在文件名中。
P207: 拼接总图后仍必须能清楚读取每张图的完整标题。
P208: 禁止出现 PASS、FAIL、通过、不通过、成功、失败 等业务判断文字。
P209: 异常现场截图使用：
P210: 发布配置模块｜配置对象｜当前已取得截图数/规定截图总数截图｜截图未完成
P211: 如果一张规定截图都没有取得：
P212: 新首页配置｜Best Companion｜0/4截图｜截图未完成
P213: 截图未完成 只描述执行状态。

P224: 3. 输入发布消息中的模型名称。
P225: 4. 点击 Search。
P226: 5. 按2秒间隔轮询页面，最长等待2分钟。

P237: 3. 截取“无搜索结果”页面。
P238: 4. 不触发重试。
P239: 5. 不标注“截图未完成”。
P240: 6. 不判断模型是否确实删除成功。

P242: 模版修改｜模型名称｜1/1截图

P303: 13. 页面查找、图片等待和重试规则
P304: 13.1 可触发重试的情况
P305: 按规定步骤找不到目标页面；
P306: 找不到目标标签；
P307: APP停留在异常页面；
P308: APP闪退或无响应；
P309: 非删除模型场景中找不到可截图的目标内容；
P310: 页面图片连续2分钟没有完成加载。
P311: 13.2 重试动作
P312: 1. 结束当前任务尝试。
P313: 2. 重启 AIMirror。
P314: 3. 恢复到首页。
P315: 4. 从当前配置对象的完整流程开头重新执行。
P316: 重试的是当前配置对象任务，不重复创建发布任务，也不重复处理 message_id。
P317: 13.3 次数
P318: 首次执行：1次；
P319: 自动重试：2次；
P320: 单个配置对象最多执行：3次。
P321: 13.4 最终仍未取得规定截图
P322: 第三次执行仍未完成时：
P323: 1. 停止该配置对象继续重试；
P324: 2. 保留最后一次异常现场截图；
P325: 3. 使用 截图未完成 标题；
P326: 4. 继续处理本次发布中的下一个配置对象；
P327: 5. 总图中保留该异常现场，不能静默删除。
P328: 13.5 不触发重试的特殊情况
P329: 发布消息明确表示删除模型，并且搜索页面显示无结果时，这是规定的正常截图场景，不触发重试。

P526: 20. 最终规则清单
P527: 1. 发布消息是截图任务的唯一业务输入。
P528: 2. 使用飞书 message_id 去重。
P529: 3. 模型、模型ID和标签都来自消息，不能完全写死。
P530: 4. 四类模块执行APP截图。
P531: 5. 国际化配置和新手引导页配置由人工直接审核，总图完全不显示。
P532: 6. 同一模型的多种修改合并成一个1张截图任务。
P533: 7. 同一模块、同一标签的多种修改合并成一个4张截图任务。
P534: 8. 普通首页标签、Video标签和Filter标签各4张。
P535: 9. New 进入页面后截图4张，入口卡片不计入。
P536: 10. 删除模型搜索无结果属于正常截图，不重试。
P537: 11. 图片最多等待2分钟。
P538: 12. 找不到页面或图片超时后重启APP，从当前任务开头重跑。
P539: 13. 首次执行之外自动重试2次，单任务最多3次。
P540: 14. 最终未完成必须保留异常现场并标注 截图未完成。
P541: 15. 每张图强制标注 模块｜对象｜序号/总数截图。
P542: 16. 没有修改的APP模块在总图中显示 模块｜本次无修改。
P543: 17. 一次发布的所有模块拼成一张总图。
P544: 18. APP自动化只负责截图，不负责判断发布配置成功或失败。
P545: 19. 当前总图只发测试群。
P546: 20. 完整链路验收和明确批准之前，正式群不得发送任何测试内容。
